# ESP32 Firmware – Smart Helmet

This directory contains the ESP32 firmware for the Smart Helmet Accident Detection and Emergency Alert System.

## Hardware Components
- ESP32
- MPU6050 Accelerometer and Gyroscope
- Alcohol Sensor
- NEO-6M GPS Module
- LED
- Buzzer

## Main Functionalities
- Motion-based accident detection
- Alcohol sensor monitoring
- GPS location acquisition
- Bluetooth communication with Android application
- LED and buzzer alerts

## Development Environment
- Arduino IDE
- ESP32 Arduino Core
- Embedded C/C++

**Main firmware:** `SmartHelmet.ino`
